# Contributing

Thank you for helping to improve Doofinder for PlentyONE.

## Reporting a problem

* Shop owners: contact [Doofinder Support](https://support.doofinder.com/pages/contact-us).
* Bugs in the plugin: open an issue with the version of the plugin, what you did and what you expected.

## Proposing a change

1. Fork the repository and create a branch.
2. Make your change. The [Development & Maintainer Guide](README.md#-development--maintainer-guide) explains how to test it on your own PlentyONE system.
3. Write your commit messages as [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`...).
4. Open a pull request that explains what changes and why.

Do not commit tunnel addresses, credentials or anything that belongs to your own PlentyONE system.
