# Doofinder

Doofinder bringt KI-gestützte Suche und Produktentdeckung in Ihren PlentyONE Shop: intelligente Suche, Searchandising, Empfehlungen und Analysen.

## Erste Schritte und Voraussetzungen

Sie benötigen einen PlentyONE Shop (PWA) und ein Plugin-Set, das im Shop aktiv ist. Ein Doofinder-Konto wird während der Einrichtung erstellt, mit 15 Tagen kostenloser Testphase.

## Einrichtung

1. Installieren und aktivieren Sie das Plugin in Ihrem Plugin-Set und stellen Sie das Set bereit.
2. Öffnen Sie die Konfiguration des Plugins und kopieren Sie die **Feed-URL** und den **Token**.
3. Melden Sie sich bei Doofinder an (oder registrieren Sie sich), fügen Sie einen Shop hinzu, wählen Sie **PlentyONE** und fügen Sie die Feed-URL und den Token ein.
4. Fügen Sie die Skript-Adresse, die Doofinder anzeigt, unter **Custom Code**, **External Scripts & Styles** Ihres PlentyONE Shops hinzu.

Doofinder liest den Katalog Ihres Shops und legt für jede Sprache eine Suchmaschine an. Verwalten Sie diese und ändern Sie, wie Ihre Artikel indexiert werden, im Doofinder-Adminbereich.

## Deinstallation

1. Entfernen Sie das Skript unter **Custom Code**, **External Scripts & Styles** Ihres PlentyONE Shops.
2. Entfernen Sie das Plugin aus Ihrem Plugin-Set und stellen Sie das Set bereit.

Durch das Entfernen des Plugins werden Ihr Doofinder-Konto und Ihre Suchmaschinen nicht gelöscht; verwalten Sie diese im Doofinder-Adminbereich.
